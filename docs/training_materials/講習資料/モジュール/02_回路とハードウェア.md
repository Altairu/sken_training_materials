# 回路とハードウェア仕様

各モジュールはマイコンとしてSTM32F446を搭載しています。
目的に合わせて入出力ピンやタイマーの割り当てが最適化されています。

## MDDモジュール

MDDモジュールのGitHubリポジトリはこちら
- [Altair_MDD_V3](https://github.com/Altairu/Altair_MDD_V3)

4つのモータを独立して制御するための回路です。
エンコーダの入力やリミットスイッチの入力にも対応しています。

### ピン割り当て

| 用途 | ピン |
| --- | --- |
| モータ1 | PB14, PB15 |
| モータ2 | PA8, PA9 |
| モータ3 | PA6, PA7 |
| モータ4 | PB8, PB9 |
| エンコーダ1 | PA0, PA1 |
| エンコーダ2 | PB6, PB7 |
| エンコーダ3 | PC6, PC7 |
| エンコーダ4 | PB3, PA15 |
| リミットスイッチ1 | PC0 |
| リミットスイッチ2 | PC1 |
| リミットスイッチ3 | PC2 |
| リミットスイッチ4 | PC3 |


## Servoモジュール

ServoモジュールのGitHubリポジトリはこちら
- [ALTAIR_SERVO_MODULE_V6](https://github.com/Altairu/ALTAIR_SERVO_MODULE_V6)

6つのサーボモータへPWM信号を出力するための回路です。

### ピン割り当て

| 用途 | ピン |
| --- | --- |
| サーボ1 | PA6 |
| サーボ2 | PA7 |
| サーボ3 | PA8 |
| サーボ4 | PA9 |
| サーボ5 | PB8 |
| サーボ6 | PB9 |


## Solenoid Valveモジュール

Solenoid ValveモジュールのGitHubリポジトリはこちら  
- [Altair_solenoid_valve_V1](https://github.com/Altairu/Altair_solenoid_valve_V1)

電磁弁を駆動するための回路です。
最大で12チャンネルの出力を備えています。

### ピン割り当て

| 用途 | ピン |
| --- | --- |
| バルブ1 | PA0 |
| バルブ2 | PA1 |
| バルブ3 | PA6 |
| バルブ4 | PA7 |
| バルブ5 | PA8 |
| バルブ6 | PA9 |
| バルブ7 | PA15 |
| バルブ8 | PB3 |
| バルブ9 | PB6 |
| バルブ10 | PB7 |
| バルブ11 | PB8 |
| バルブ12 | PB9 |

状態確認用のLEDが全モジュール共通でPA5に接続されており、通信状態の確認に利用できます。
