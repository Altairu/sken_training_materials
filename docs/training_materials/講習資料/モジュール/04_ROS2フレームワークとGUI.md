# ROS2フレームワークとGUI

モジュール群を一括で管理し、ROS2やブラウザから簡単に制御するための統合パッケージとして`altair_framework`が提供されています。
ロボット側のプログラムを書き換えることなくモジュールの構成を変更したり、コントローラでの操作や自律動作のプログラムを実行できます。

- [altair_framework](https://github.com/Altairu/altair_framework)
